## 📌 About This Repository

Learning data science without hands-on coding creates the "tutorial trap." This repository is the companion codebase for our weekly Amharic video series on [Data With Muhamed](https://youtube.com/@datawithmuhamed). 

Every folder corresponds to a foundational milestone in modern Python engineering:
- **Clean, runnable scripts** with inline comments and Amharic explanations.
- **Real-world context** linking syntax directly to Data Cleaning, EDA, and Machine Learning.
- **End-of-lesson mini-challenges** to test your problem-solving skills.
